# Vendor's Market

Vendor's Market is a proposed commerce platform for customers, retail vendors, and wholesale businesses in Nepal.
The project is currently in product definition and design; application setup and implementation belong to Phase 1.

## Phase 0 deliverables

- [Product definition, workflows, and acceptance criteria](docs/product/phase-0-product-definition.md)
- [Interactive customer, vendor, and administrator design prototype](docs/design/phase-0-prototype.html)

The product definition records proposed policies that still need approval by the Product Owner. The prototype uses
illustrative data and does not connect to a backend or process real orders or payments.
